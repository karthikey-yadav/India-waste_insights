# India Waste & Plastic Pollution Dashboard

A state-wise analysis of municipal solid waste and plastic waste processing gaps
across India, with trends and priority recommendations.

## Tech stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Recharts

## Development

Requires Node.js (v18+) and npm.

```sh
git clone https://github.com/karthikey-yadav/india-waste-insights.git
cd india-waste-insights
npm install
npm run dev
```

The app will be available at `http://localhost:8080`.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
- `npm run format` — run Prettier
